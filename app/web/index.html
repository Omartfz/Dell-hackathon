What this is

This is a corporate spend platform — cards, invoices, vendor payments — with a privacy layer built into it. An AI agent runs locally on the Dell GB10 and reasons about every transaction and document as it arrives.

Most it settles on the box, where nothing leaves. For the few hard cases that need a bigger cloud model, it first strips the payload to the minimum that model actually needs: names become aliases, amounts become bands, and card numbers and bank details never leave at all.

A model that never sees an account number cannot leak one.

How every event is handled

Tier 0 · Rules Deterministic scoring. ~97% of events end here. 0 bytes leave.
Tier 1 · Local AI The GB10 model reasons about the raw record. 0 bytes leave.
Tier 2 · Escalated Hard, high-value cases only. Minimized payload leaves.

Tiers 0 and 1 need no internet at all. Unplug the box and the agent keeps working — only Tier 2 queues up.

Controls

Retrieval that changes behaviour — edit a document, not the code

These rules decide what may leave the box. They are ordinary MongoDB documents, so changing who someone is — or what their role may see — takes effect on the very next escalation. Try the Role button on the home page and watch a payload change.

Policies stored in MongoDB

Flip the role or edit a policy and the very next escalation produces a different payload. No redeploy, no restart, no new model.

MongoDB

The database is the runtime, not a store

MongoDB does not just hold this data — it drives the agent. Change streams wake it up, aggregation pipelines do the analysis, and the agent's own memory lives in a collection so it can survive being killed. None of this works as a JSON file.

The agent survives its own sandbox

The stream is driven by a change stream, not a poller. Every event checkpoints its resume token to agent_state, and each event id is claimed in processed_events under a unique index. Kill the process and it resumes at the exact position — and cannot redo work.

Payables

Scheduled vendor payments — the invoice stream

Invoices are where fraud arrives. The agent reads every body locally, and flags any that try to give it instructions — a real vendor never writes "ignore previous instructions" on an invoice, so the attempt is itself evidence.

Cards

PANs are catalog-floored — they can never leave the box

Full card numbers exist in the database, but the server strips them before they even reach this browser, and no AI request can ever include one. That rule sits below policy: nothing can switch it off.

Treasury

Cash, burn and runway — MNPI, banded before any escalation

Pre-release financials are material non-public information. Your team sees exact figures; a cloud model only ever sees a range like "$1M–$5M", which is enough to reason with and useless to leak.

Research

Public company data — the one surface where egress is unrestricted

Public filings carry nothing to protect, so this screen would route straight to a cloud model. Every other screen in this console is local-only. Same app, two data-residency regimes, decided by what the data is.
